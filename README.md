# Kadr i Czas

Responsywny, niezależny od zewnętrznych bibliotek katalog filmów i seriali. Wszystkie tytuły i metadane są fikcyjną treścią demonstracyjną; strona nie zawiera odtwarzacza ani linków do transmisji.

## Uruchomienie lokalne

Otwórz `index.html` bezpośrednio w przeglądarce lub uruchom folder przez dowolny statyczny serwer WWW.

```sh
python -m http.server 8000
```

Następnie otwórz `http://localhost:8000`.

## Funkcje

- Wyszukiwanie według tytułu, twórcy, obsady, gatunku lub nastroju
- Filtrowanie filmów i seriali według gatunku
- Lokalne zapisywanie tytułów w przeglądarce
- Skrót klawiaturowy (`/`) uruchamiający wyszukiwanie
- Responsywne i dostępne okno szczegółów
